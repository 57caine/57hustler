# Claude への作業受け渡し手順（claude-task / claude-in-progress）
更新日：2026-11-05（JST）

## 目的
既存の自走タスク（ChatGPT「57hustler 集客改善の自走」毎朝8時JST、GitHub Actions の各ワークフロー）は止めずに、
Claude（Claude Code の予約タスク、1日1回）に楽旅くんの改善を個別に渡すための手順。
ラベルで「誰が持っている作業か」をはっきりさせ、同じ作業を二重に進めないようにする。

## CEO判断（2026-11-05）
- 既存の自走タスクは停止しない
- Claude は楽旅くん（`rakutabi/`）の改善を優先する
- 専用ラベルで既存タスクとの重複を防ぐ
- 予約タスクはまず1日1回
- Claude の実装は **下書きPR（Draft PR）作成まで**。本番公開・マージは禁止
- API従量課金・追加課金は禁止（`ANTHROPIC_API_KEY` 等を使う処理を新たに動かさない）

## ラベル
| ラベル | 意味 | 付ける人 |
|---|---|---|
| `claude-task` | Claude に任せる作業。予約タスクが拾う候補 | オーナー（またはオーナー指示を受けたChatGPT） |
| `claude-in-progress` | Claude が着手済み。他のエージェントは触らない | Claude（着手時） |

## 受け渡しの流れ
1. **依頼する（オーナー側）**：Issue を作り `claude-task` を付ける。テンプレート「Claude依頼（楽旅くん）」を使うと必要事項が埋まる。
   1 Issue = 1 件の改善。対象ページ・困っていること・完了の条件を書く。
2. **着手する（Claude）**：予約タスクが `claude-task` 付き・`claude-in-progress` なしの Open Issue を古い順に1件だけ選び、
   `claude-in-progress` を付けて「着手しました」とコメントする。
3. **実装する（Claude）**：`claude/rakutabi-issue-{番号}` ブランチで実装し、検証（`rakutabi/` で `npm run lint` と `npm run build`）を通して
   **Draft PR** を作る。PR本文に `Refs #{番号}`、変更内容、検証結果、戻し方を書く（`Closes` は使わない。マージはオーナー判断のため）。
4. **報告する（Claude）**：Issue に Draft PR のリンクと結果をコメントする。ラベルは `claude-in-progress` のまま残す（PRレビュー待ちの目印）。
5. **判断する（オーナー）**：Draft PR を確認し、マージするか見送るかを決める。終わったら Issue を閉じる。
   見送り・やり直しの場合は `claude-in-progress` を外せば、次回の予約タスクで再度拾われる。

## 止まるべき場面（Claude は実装せず Issue にコメントして終了）
- 同じ Issue を参照する Open PR が既にある（Claude 以外が作ったものも含む）
- 直近24時間以内に、同じ Issue へ Claude 以外のエージェントが作業中とコメントしている
- 作業内容が `rakutabi/` 以外に及ぶ、または下記の禁止事項に触れる
- 依頼内容が曖昧で、オーナーの判断なしには進められない

## Claude の禁止事項
- PR のマージ、本番公開（`rakutabi/scripts/vercel-deploy.sh` の実行、Vercel CLI、main への push）
- `.github/workflows/` の変更（公開処理や有料APIを使う処理が動く可能性があるため）
- `data/yonaka-feedback.json` の変更（push 時に有料APIを使うワークフローが起動するため）
- アフィリエイトURL・送客先・価格の計算式・計測の意味や範囲・noindex・認証/権限の変更
- 新規の有料サービス・API キーの利用

## 既存の自走タスク側のルール（重複防止）
- `claude-task` または `claude-in-progress` が付いた Issue、および `claude/` で始まるブランチの PR には着手しない
- `docs/rakutabi-growth-loop.md` の継続承認（小さな改善のマージ・公開）は既存タスク側のもので、Claude には適用しない

## 予約タスクの設定状況（2026-11-05）
- 会話内のClaudeから予約タスク「楽旅くん claude-task 日次」（ID `trig_01N9evbNxyZjamVRMi2LDkTT`、毎日11:13 JST）を作成し、試し実行した
- 結果：作成自体はProプランの契約内で成功した。ただし、この方法で作った予約タスクにはリポジトリとGitHub接続が付かず、
  試し実行では「GitHubに接続できず中止」（何も変更なし）となった。このため **一時停止（無効化）** にしてある
- 有効にするには、オーナーが claude.ai/code の「予約タスク（Scheduled tasks / Routines）」画面から、リポジトリ `57caine/57hustler` を選んで
  新しく作成する。指示文は下記をそのまま貼る。頻度は1日1回（例：11:13 JST）。作成後、上記の停止中タスクは削除してよい
- Proプランの日次実行回数には上限がある（公開資料では1日5回、現在の残り回数は claude.ai/code/routines または claude.ai/settings/usage で確認）。
  追加課金を防ぐため、claude.ai/settings/usage で「追加利用（Extra usage）」がオフであることを確認する

### 予約タスクに貼る指示文
```
あなたは 57caine/57hustler リポジトリの楽旅くん（rakutabi/）改善担当です。1日1回の予約実行です。手順は docs/claude-task-handoff.md（main に無ければブランチ claude/rakutabi-task-setup-n1pj3m の同ファイル）に従います。報告は日本語。

【0. 準備】GitHubのIssue一覧が読めない・ラベル変更やPR作成ができない場合は、何も変更せず「GitHubに接続できず中止」とその理由を最終報告に書いて終了する（回避策を試さない）。

【CEO判断・絶対ルール】
- 実装は下書きPR（Draft PR）作成まで。PRのマージ、本番公開（rakutabi/scripts/vercel-deploy.sh、Vercel CLI、mainへのpush）は禁止
- API従量課金・追加課金は禁止。ANTHROPIC_API_KEY 等の有料APIを使う処理を実行しない
- .github/workflows/ と data/yonaka-feedback.json は変更しない（pushで有料APIのワークフローが起動するため）
- アフィリエイトURL・送客先・価格の計算式・計測の意味や範囲・noindex・認証/権限は変更しない
- 既存の自走タスク（ChatGPT日次タスク、GitHub Actions）は止めない・設定を変えない
- 作業対象は rakutabi/ 配下のみ。1回の実行で扱うIssueは最大1件

【手順】
1. Open かつ `claude-task` ラベル付き、かつ `claude-in-progress` ラベルなしのIssueを作成日の古い順に探す。0件なら何も変更せず「対象なし」と記して終了。
2. 候補Issueについて次を確認し、該当すればそのIssueに理由をコメントして終了:
   - そのIssueを参照するOpen PRが既にある（作成者を問わない）
   - 直近24時間に、Claude以外が同Issueで作業中とコメントしている
   - 作業が rakutabi/ 外に及ぶ、または上記禁止事項に触れる、または内容が曖昧でオーナー判断が要る
3. 着手するIssueに `claude-in-progress` ラベルを追加（既存ラベルは残す）し、「着手しました」とコメント。
4. 最新mainから `claude/rakutabi-issue-{番号}` ブランチを作り実装。rakutabi/AGENTS.md・rakutabi/CLAUDE.md・ルートCLAUDE.mdのルールに従う。rakutabi/ で npm ci → npm run lint → npm run build を実行し結果を記録。
5. ブランチをpushし、base=main の Draft PR を作成。本文: Refs #{番号}（Closes は使わない）、問題、変更内容、検証結果、戻し方、未確認事項。
6. IssueにDraft PRのリンクと結果をコメント。`claude-in-progress` は残す。失敗した場合も理由をコメントし、ラベルは外さない。

GitHubへのコメント・PR本文の最後には次のフッターを付ける:
---
_Generated by [Claude Code](https://claude.ai/code)_
```
