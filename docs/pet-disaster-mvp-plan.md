# ペット防災：6週間の最小収益検証計画

作成日: 2026-10-17 / 状態: 設計案（サイト公開・商品リンク未実装）

## 方針
犬向け防災用品の3テーマで開始し、猫・小動物は検証後に拡張する。検索需要、競合、楽天での販売状況・規約を調査してから商品を選定する。根拠のない「おすすめ1位」や架空の口コミを掲載しない。

## 初期ページ案
1. 犬の避難キャリー・クレート：体格・重量・扉・通気・避難所ルールの確認項目
2. 犬の携帯食器・給水：容量・素材・洗いやすさ・持ち運びやすさ
3. 犬の排泄対策：トイレシート・袋・消臭・廃棄方法

各ページに対象・選び方・比較表・注意点・楽天への購入先リンクを配置する。商品データと価格は取得時点・出典を記載し、在庫・価格は購入先で確認するよう案内する。

## 安全・品質
- 災害時の同行避難と避難所での同伴可否は別。自治体・避難所のルールを確認するよう明示する。
- 環境省等の一次情報に基づき、誤解を招く防災・医療断定をしない。
- 広告リンクは適切に識別する。楽天アフィリエイトのサイト登録・リンク形式・API利用条件を公開前に確認する。
- 既存サイトの広告IDを無断で流用しない。追加課金・独自ドメイン取得はしない。

## 計測
イベント: page_view、product_compare_click、affiliate_click（商品ID・ページ・位置）。個人情報を収集しない。サイト内クリックと楽天側の確定成果は区別する。

## 6週間の判定
第1週: 競合/需要/商品/規約調査、3ページ設計
第2週: MVP制作・計測・表示検証
第3〜4週: SNS/検索流入の試験、導線の改善
第5〜6週: 実測した流入、クリック、成果で継続・修正・停止を判定

## 公開ゲート
商品リンクの実在、正しいアフィリエイト帰属、広告表示、計測、モバイル表示、出典、公開先のデプロイ成功を確認するまで本番公開しない。
