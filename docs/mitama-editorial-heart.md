# MITAMAの編集方針（2026-11-10）

目的は旅の案内や日本語辞典ではなく、日本の暮らしにある心を英語で伝えること。言葉シリーズは残すが中心に固定しない。

次の7本を準備するときは、暮らしの具体的場面と他者への配慮を3本、自然・物への敬意を1本、目立たない善意や内省を1本、言葉紹介を最大2本の目安にする。毎回同じ翻訳説明と「あなたの言語では？」で終えない。質問は読者が自身の暮らしを考えられる具体的なものにする。
