# 楽旅くん・楽天アフィリエイト公式計測IDの導入準備

対象：2026年12月2日〜30日のThreads隔日投稿15本（day25〜39）

## 完了していること

- 楽天トラベルの施設ページと、楽天アフィリエイトのリンクに埋め込まれた施設番号が一致するか、毎回自動検査する。
- `node scripts/audit-rakutabi-rakuten-links.mjs` で15宿・投稿日・提案するID（`rkt25`〜`rkt39`）の一覧を生成する。
- **提案IDは未発行。** この設定だけでは楽天レポート上の宿別クリック・成果は取れない。
- 現在の予約済み15投稿の楽天アフィリエイトURLは一切変更していない。

## 楽天側の公式な操作が必要な段階

公式案内: https://affiliate.rakuten.co.jp/guides/link/
計測ID設定: https://affiliate.rakuten.co.jp/user/sites
集計: https://affiliate.rakuten.co.jp/guides/report/

1. ログイン済み楽天アフィリエイトの計測ID画面で、希望するIDを作成する。提案名は `rkt25`〜`rkt39`。すでにIDがあれば既存名称でもよい。
2. 各ホテルの楽天トラベル**正確な施設ページ**から公式のリンク作成画面を開き、該当する計測IDを選択して楽天が生成する**リンク全文**を取得する。
3. 正式リンクと対象ホテルIDの対応を照合して、既存投稿データの `bookingUrl` を正規リンクで置換し、dry-run・安全テストを実行する。**URLを推測して組み立てたり、独自のクエリパラメータを追加してはいけない。** 正規リンクがこのリポジトリで対応していない形式の場合は確認・検証してから採用する。
4. 楽天レポートで計測ID別にクリック・発生成果・確定成果を照合する。注文/報酬の反映には時間差がある。確定済み以外は確定報酬に数えない。

公式案内は計測IDを作成・選択してアフィリエイトリンクを生成することを要求する。未認証のGitHubアクションで楽天側のIDを自動作成できたと主張してはならない。

楽天によるリンク改変禁止: https://affiliate.faq.rakuten.net/detail/000001107
（楽天の公式ガイドの計測設定のみ使用し、リダイレクトやサードパーティ短縮URLは使用しない。）

**注意**：`Rakuten STAY` などの掲載宿と、それ以外の宿で宿泊人数・宿泊日・金額は揃っていないため、投稿閲覧が多いだけで利益優位と判断しない。Metaの投稿インサイトは楽天の発生・確定報酬を示さない。
