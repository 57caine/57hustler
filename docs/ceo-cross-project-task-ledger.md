## 運用ルール
1. 「今日やることは？」「もうない？」への回答前に、この台帳・projects-registry・open PR・直近Actions・会話中の未完了事項を突合する。

3. `進行中`・`検証待ち`・`保留`・`未確認` を区別。保留や未確認を完了にしない。
4. 事業横断でAI担当とオーナー本人の操作を分離し、本人の作業は認証・承認等の必要最小限にする。
5. この台帳だけを真実とせず、更新日が古い場合は現物確認。公開リポジトリに認証情報・家族・資産など機微情報を置かない。
