# ペット防災：犬向けMVP（2026-10-17）

## 目的と制約
- 6週間で検索需要と楽天市場への送客を検証する。売上保証はしない。
- 新規課金なし。既存57hustlerの公開設定や既存サイトの動作を変更しない。
- 対象は最初は犬。猫・小動物は計測結果を見てから。
- 製品の性能・安全性・価格・在庫・レビュー・アフィリエイト成果を未検証のまま断言しない。
- 環境省資料に基づく防災情報と、販売店の商品情報を明確に分離する。

## 初期ページ案
1. /dog/evacuation-carrier — 犬の避難キャリーの選び方。サイズ・重量・耐荷重・通気・持ち運び・普段の慣らしを比較。
2. /dog/water-food — 携帯給水器・折りたたみ食器の選び方。容量・洗いやすさ・漏れ・保管を比較。
3. /dog/toilet — 犬の避難時トイレ用品。トイレシート・消臭袋・衛生管理・ごみ持ち帰りを整理。
4. /dog/checklist — 持ち出し用品チェックリスト。水・フード・常備薬・鑑札等・写真・連絡先・ケージを点検。

## 重要な編集ルール
- 「同行避難」はペットとともに安全な場所まで避難することで、避難所内で人とペットが同室で過ごせる保証ではない。自治体と避難所のルールを確認する。
- 飼い主と家族の安全確保が優先。ペットは普段からキャリー・ケージに慣らす。
- 医療・服薬・必要量の個別判断は獣医師等に確認。
- アフィリエイトリンクを掲載する際は広告表示と運営者情報を整備する。
- 楽天の商品ページURLと報酬対象の追跡URLを区別し、未確認のURLは掲載しない。

## 計測・検証
- 計測：ページ表示、商品比較への遷移、楽天への送客クリック（ページ別・カテゴリ別）、成果（楽天管理画面）。
- 週1：表示回数・検索クリック・送客クリック・売上を確認。未取得はゼロ扱いしない。
- 2週目：掲載商品の在庫・リンク・誤情報を監査。
- 4週目：反応があるカテゴリの導線を改善。
- 6週目：継続・拡張・停止を判断。PVや売上の架空数値は記載しない。
