# 楽旅くん：写真で旅を提案する投稿案
更新日：2026-11-01 JST。状態：下書き・実装条件の整理。投稿器未実装、写真未確保、未公開。

## 今回のオーナー指示
共有された参考投稿のように、親しみやすい短文・写真多め・具体的な宿の魅力から該当リンクへつなぐ。「PRも外して」との希望あり。参考アカウントの写真・文章・価格は転載しない。反応数を楽旅の売上予測に使わない。

## 目指す構成
1. 親投稿：体験したくなる特徴を一つ、80〜140字程度。絵文字1〜3個。価格より過ごし方を先に。写真は使用条件を満たす実物2〜4枚を目安とする。
2. 続き：宿名・地域、一次情報で確かめた特徴を3点程度、条件と予約先。写真と紹介する客室・プランを一致させる。
3. 保存の呼びかけは自然な一言にとどめ、煽り・架空の実泊体験・常時最安・根拠のない残室表現は使わない。
4. 価格を載せる場合は検索日時・宿泊日・人数・一室人数・食事条件・税等を確かめる。未確認なら金額を省く。
5. 宿紹介なら既存承認済み宿別リンク、地域紹介なら該当地域の既存宿一覧へ。新しい外部アフィリエイトURLは作らない。

## PR表記の扱い
楽天公式説明は全投稿一律必須ではない。基本機能のみで事業者との情報等のやり取りがない投稿では任意の場合がある。一方、提供・謝礼・個別施策・投稿内容への関与がある場合は、最初に見える位置に「広告」「PR」等が必要。
対象宿ごとに提供や個別依頼の有無を未確認のため、全件自動削除はまだ行わない。任意と確認できた新規原稿ではPR文字を外す希望を反映し、必要な案件では明確な広告表示を残す。末尾や返信だけに隠さない。
参考画像の返信にも小文字のprが見えるが、第三者の表示方法を我々の判断根拠にはしない。
公式：https://affiliate.rakuten.co.jp/guideline/stealth_marketing_regulation/ （11/1本文取得）。

## 写真の確保
楽天公式ページの検索結果にはAPI画像のSNS投稿を控える旨が表示されたが、今回の本文抽出では当該節を取得できなかった。SNS転載許諾が確認できた状態とは扱わない。
参照：https://travel.rakuten.co.jp/affiliate/guide/ 、https://travel.rakuten.co.jp/distributor/affiliate.html 、https://affiliate.rakuten.co.jp/know-how/susumeru/ 。
使用可能な候補は、自己撮影の権利確認済み写真、または宿・観光協会等が商用SNS利用と必要な加工・再配信を明示して許諾した写真。取得元URL、対象宿、権利者、利用条件、確認日、クレジット、期限を素材ごとに記録する。現在その条件を満たす写真は未確保。
公式サイト上にあるだけの写真や他者投稿の保存画像は使わない。API画像や楽旅サイト表示用の写真をSNS用に流用しない。AI画像を実在宿の客室や眺望として使わない。

## 実装の残件
現行 scripts/post-organic-threads.mjs はTEXT一件のみ。画像付き親子連投の自動化は未実装。
別の実装PRで現行Threads公式仕様、画像公開URLの到達性、許諾、代替テキスト、画像処理状態を検証する。
親・返信の公開IDを段階別に永続保存し、親のみ成功・返信失敗・応答不明でも重複公開しない。曖昧なpublish応答は安全停止し履歴照合、勝手に再送しない。
テスト対象：既存TEXT回帰、画像未許諾拒否、アカウント不一致、日付境界、重複、部分成功、応答不明、画像準備失敗。CI後に具体的な一件の原稿・写真・リンクを示し公開承認を受ける。
現在の期限・頻度・アカウント照合・重複防止・リンク・原稿は今回変更しない。伊東の72時間評価（11/3 15:59 JST以降）と確定7日評価を優先し、評価前に別地域へ展開しない。
