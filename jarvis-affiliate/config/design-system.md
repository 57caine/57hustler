# デザインシステム（LP共通ルール）

LPの見た目と構成の「型」です。エージェントはLPを作る・直すときに必ずこのファイルに従います。
色やフォントを変えたいときは、このファイルと `src/styles/global.css` の `@theme` を同時に直します。

## 1. 配色（トークン）

| 役割 | トークン | 値 | 使う場所 |
|---|---|---|---|
| メイン | `brand-600` | `#0369a1` | 見出しアクセント・リンク |
| 濃色 | `brand-900` | `#0c2d48` | 見出し文字・フッター |
| CTA | `cta-500` | `#ea580c` | 申込ボタン（ページ内で一番目立つ色はCTAだけ） |
| CTAホバー | `cta-600` | `#c2410c` | ボタンのホバー |
| 背景 | `surface` | `#f8fafc` | セクション背景の交互配置 |
| 注意 | `amber-50/700` | Tailwind標準 | 注意書き・PR表記 |

- CTA色（オレンジ）はボタン以外に使わない。「押せる場所＝オレンジ」を徹底すると迷わせない
- 赤は警告にだけ使う

## 2. タイポグラフィ

- 本文：16px（モバイル）/ 17px（PC）、行間 1.8、日本語は `Noto Sans JP` → システムフォントの順
- 見出しH1：28px（モバイル）/ 40px（PC）、太字
- 1文は60字以内、1段落は3文以内を目安にする（スマホで3行以内）

## 3. CVRを高めるLP構成（上から順に固定）

1. **PR表記バナー**（自動）
2. **ファーストビュー**（`HeroSection`）：悩みへの共感 → ベネフィット → CTA＋マイクロコピー
   - 見出しは「誰の・どんな悩みが・どうなるか」を1文で
   - CTAの下に不安を消すマイクロコピー（例：「無料体験だけでも申込OK・1分で完了」）
3. **結論ファースト**：おすすめ1位を最初に1行で言い切る
4. **比較表**（`ComparisonTable`）：全列ソート可。3〜5社に絞る
5. **ランキング詳細**（`RankingCard`）：「こんな人におすすめ」→ 理由 → 注意点 → CTA
6. **本文**（キャンペーンMDの本文）：選び方・使い方・よくある失敗
7. **FAQ**（`FaqSection`）：申込前の不安を3〜6問で潰す
8. **最終CTA**：1位案件のボタンを再掲

## 4. CTAボタンのルール

- ラベルは「行動＋得られるもの」：「無料体験を予約する」「公式サイトで料金を見る」
- 「こちら」「クリック」だけのラベルは禁止
- 1画面にCTAは最大2つまで
- ボタンには必ず案件名を添える（どの商品のリンクか分かるように）

## 5. 画像

- 商品画像は `affiliates.json` の `image` にASP提供のバナー/商品画像URLを入れる。空ならアイコン表示
- 画像には `width`/`height` と `loading="lazy"`（ファーストビュー以外）を付ける
