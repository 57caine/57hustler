# /new-lp — 新しいLPを作る

入力：$ARGUMENTS

`CLAUDE.md`・`JARVIS-2.0-SPEC.md`・#207/#209・`config/design-system.md`・`config/compliance-rules.md` を読んでから始めること。

## 手順

1. **情報を集める**（#207の既存台帳と無料・権限済み経路を先に確認。本人判断・認証が必要な不足だけ1回にまとめ、最大5問）
   - ターゲット（誰が・どんな状況で）
   - 悩み3つ／得られること3つ
   - 紹介する案件と、ASPで発行したリンク（A8・もしも・楽天など）
   - ランキング1位にしたい案件（理由）
   - 薬機法・金融などの規制カテゴリに当たるか
   - 入力に足りない情報は推測で埋めず、`TODO:` と書いて質問リストに入れる

2. **既存の登録を確認する**（二度手間防止）
   - `config/affiliates.json` に同じ案件がないか `id`・`name`・`url` で検索
   - `content/campaigns/` に似たテーマのLPがないか確認。あれば新規ではなく改修を提案する

3. **案件を登録する**：`config/affiliates.json` の `programs` に追記
   - `id` は半角英小文字＋ハイフン、`status: "active"`、`dummy` は付けない（実リンクの場合）
   - `asp` に応じたリンク形式か確認（`src/lib/affiliates.ts` の `ASP_RULES`）
   - `specs` は公式サイトで確認できた値のみ。確認日を `verifiedAt` に入れる
   - **リンクがまだ無い場合**は `dummy: true` で仮登録し、報告の「判断してほしいこと」に「ASPでの提携申請・リンク発行」を書く

4. **キャンペーンMDを作る**：`content/campaigns/_template.md` をコピーして `content/campaigns/{slug}.md` を作成
   - 最初は `status: draft`
   - 構成・コピーは `design-system.md` の3章・4章に従う
   - `comparison.columns[].key` は全案件の `specs` に存在するキーにする

5. **検証する**
   ```bash
   npm run validate
   ```
   - ERROR は全件直す。WARN は内容を確認し、直せないもの（ダミーリンク等）は報告に残す
   - `status: draft` を維持して `npm run build`。draftが生成対象外ならHTML検証は未実施と明記する。一時publishedへの変更は禁止。非公開draft検証経路が未実装ならその不足を報告する
   - draftのHTMLが安全なローカル検証経路で生成された場合だけ、全案件名・PR表記・全ボタンのsponsoredを確認。localhost限定、外部共有・本番GA4送信なし

5b. **需要・採算ゲートを確認する**（現行コードは未実装。仕様書§1〜§3で手順として確認）
   - 対象顧客・購入意図・需要根拠/確認日・無料集客経路・競合との差を確認し、pass/fail/insufficient_dataと理由を記録
   - 予測と実績を分離し、各率/単価の出典・仮定・幅、費用・工数、事前採算基準を確認。欠測はnull、利益不明なら保留
   - ASP提携と条件・禁止表現・計測可能性を確認。サンプルや発生報酬を確定実績として通さない

6. **draftを維持し、公開判断を分離する**
   - ビルド成功・実リンクだけでpublishedにしない。今回の#209では本番公開は禁止
   - 後続の公開実験は需要/予測採算/品質/ASP条件と#207の明示公開承認（対象・範囲・SHA・仕様版・上限）を全て確認するまでdraft
   - 量産はさらに確定報酬照合、実績採算、十分な観測分母と再現性の合格、別の量産承認が必要
   - approvals.jsonは未実装の保存形式案。ファイルの存在やAI自己申告、一般のGO・ラベルだけを承認としない
   - 元Claudeブランチへの直接push/mainマージ/SNS変更/課金は禁止。派生ブランチのDraft PRまで

7. **報告する**（この形式で）
   - 作成・変更したファイル
   - 検証結果（実行済みチェックだけを証拠付きで記載。未実施/対象外を分離）
   - 需要・採算・照合・承認ゲートの結果、不足、#207への次の一手1件、再開条件
   - LPのURL（ローカル：`/lp/{slug}/`）
   - 判断してほしいこと（ランキング順・ダミーリンクの差し替え・規制カテゴリなど）
