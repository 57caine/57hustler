# 熟ドロ 戦略レビュー用まとめ（2026-11-23時点）

ChatGPTへのお願い：以下は熟ドロ（熟女泥棒）のテスト版の現状と戦略です。末尾の「レビューしてほしい点」を中心に、改善点・見落とし・リスクを指摘してください。実装の担当はClaudeで、オーナーは非エンジニア（Webマーケティング経験あり）です。

## 1. 事業の目的とゴール

- 一人企業で、手を動かさず自動で収益が入る仕組みを作る。
- 熟ドロは、アダルト動画のアフィリエイトメディア。
- **ゴール（コンバージョン）**：紹介先に送客したあとの「単品購入」または「月額サブスク登録」。
- 紹介先：FANZA（DMMアフィリエイト）が主力。Fantiaは公式の取得手段が見つかっていないため、架空データ6件のまま。MyFansも公式の提携手段は未確認。

## 3. データ

- DMMアフィリエイトAPI（v3 ItemList、FANZA動画）から取得。API用アフィリエイトIDは `nsplot-990`。
- 取得条件：キーワード「熟女」「人妻」「寝取り・寝取られ」「30代」「40代」をそれぞれ人気順420件。VR専用は除外。
- **1,669作品**（カテゴリ重複あり：熟女859・人妻987・NTR 450・30代435・40代440）
  - サンプル動画あり：1,503作品（FANZA公式プレイヤーを埋め込み）
  - セール中：641作品（取得時点）
  - 見放題chにも含まれる：911作品（見放題ch 630・デラックスのみ281）
- FANZA上の総件数：熟女・人妻は5万件超、NTRは約2.2万件、30代は769件、40代は804件（キーワード一致）。
- **データは固定**：毎日更新はせず、一度入れた作品で数値検証する方針（オーナー判断）。終了したセールは自動で表示しない。
- 掲載比率：当初は「FANZA 7：Fantia 3」の予定だったが、作品数を優先して FANZA全件＋Fantia架空6件で可とした（オーナー判断）。

## 4. サイト構成と導線

**トップ**
1. 特集カルーセル3枠：熟女特集（861）／人妻特集（991）／フェラ特集（147、FANZAジャンル「フェラ」）
2. 検索（作品名・出演者・カテゴリ・タグ）
3. 絞り込み：提供元（すべて/FANZA/Fantia）、「見放題で見られる作品」、「セール中」、カテゴリ（熟女→人妻→NTR→30代→40代）
4. 作品一覧（40件ずつ「もっと見る」）。並び：人気順・新着順・作品名順・割引率が高い順・セール終了が近い順
5. タグから探す、出演者から探す（作品数上位16人）、人気ランキング

**作品カード**：画像、提供元、カテゴリ、「見放題」印、タイトル、出演者、価格（定価より安ければ取り消し線）、「セール◯%OFF」、終了7日以内は「セールあと◯日」、タグ2つ、「▶ サンプル」、「本編を見る」ボタン、保存（♡）

**サンプル再生**：カード内でFANZA公式プレイヤーを再生。「全画面」ボタン（iPhoneは画面いっぱい表示で代替）。再生中は下に「続きは本編で ▶ 本編を見る」。

**作品詳細**（`#w-作品ID`）：タイトル直下に購入ボタン2つ
- 「本編をFANZAで見る」（単品の最安値を併記）
- 見放題対象なら緑の「見放題chで見る（月額¥3,980・この作品も見放題）」。デラックスのみ対象ならデラックス（月額¥8,980）
- 比較表示：「最安¥300の単品を14本以上見るなら、見放題chのほうが安くなります」（実数で計算）
- その下に作品情報（出演者リンク、メーカー、配信開始、価格、見放題、セール）、作品概要、タグ、関連作品

**出演者ページ**（`#p番号`）：出演作品一覧、見放題対象本数、セール本数。見放題2本以上なら月額バナー。

**保存一覧**：保存した作品のうち見放題で見られる本数と単品合計（最安値）を表示。月額以上なら「見放題のほうがお得です」、未満なら「あと約◯本見るなら見放題のほうがお得です」＋見放題chボタン。

**外部遷移**：テスト版では確認画面を挟み、「本編を見る」で本物のアフィリエイトリンク（`af_id=nsplot-990`、`rel="sponsored noopener noreferrer nofollow"`、新しいタブ）。本番では確認画面なしで直接移動する想定。

## 5. 文言・表記の方針

- ボタンは「購入」より心理的負担の軽い「本編を見る」型。
- 「本編を見る」ボタンにはPR表記を付けない（オーナー判断）。代わりにページ上部に「当サイトはアフィリエイト広告を利用しています」を常時表示。特集カルーセルにはPR表記あり。
- 価格・割引率・セール終了日・見放題対象はすべてAPIの実データから計算。「残りわずか」など根拠のない表現は使わない。
- 見放題対象作品の単品最安値は多くが300円前後（630本中、800円以上は16本）。そのため「数本で元が取れる」とは言えず、実数で比較を見せている。
- DMM指定のクレジット「Powered by FANZA Webサービス」をフッターに改変なしで表示。

## 6. 計測（テスト環境内のみ）

ブラウザ内に記録（外部送信なし、GA4未導入）。

| イベント | 内容 |
|---|---|
| view_item | 詳細表示。経路（一覧・ランキング・関連作品・出演者ページ・直接）と一覧での順位 |
| sample_play / sample_fullscreen | サンプル再生と全画面 |
| outbound_click | 購入ボタン。作品ID、提供元、plan（単品 / 見放題ch / デラックス）、ボタン位置（一覧カード、詳細、サンプル上、保存バナー、出演者バナーなど） |
| outbound_open | 確認画面から実際に外部リンクを開いた |
| select_tag / view_actress / filter_sale / filter_monthly / list_more | 回遊・絞り込み |

**限界**：クリックまでは測れるが、購入・登録の成果はDMMアフィリエイトの管理画面でしか分からない。

## 7. 決まっていないこと・リスク

1. **本番の公開先**：レンズナビのVercelは、アカウント停止やAmazon・楽天・A8の審査への波及リスクがあるため使わない方針。アダルト可のレンタルサーバー＋専用ドメインを推奨しているが未決定。
2. **年齢確認画面**：未実装。
3. **画像・サンプル動画の利用条件**：DMMの規約で埋め込みが認められている前提で実装。規約の該当箇所は未確認。
4. **検索流入**：詳細ページは `#` 付きURLのため、検索エンジンに個別ページとして認識されない。SEOを狙うなら作品ごとのページ生成が必要。
5. **データ量**：fanza.json は約1.7MB。スマホの初回表示が重くなる可能性がある。
6. **価格の鮮度**：データ固定のため、検証期間が長いと価格・セールがずれる。
7. **集客チャネル**：SNS・広告・SEOのどれで人を連れてくるか未決定（アダルトは広告・SNSの制限が強い）。
8. **Fantia・MyFans**：公式の取得・提携手段が未確認。

## 8. レビューしてほしい点

1. 「単品（本編を見る）」と「月額（見放題ch）」の見せ方・順番・文言は、CVRを上げるうえで妥当か。
2. 特集カルーセル（熟女・人妻・フェラ）とカテゴリの並び（熟女→人妻→NTR→30代→40代）は、狙う客層に合っているか。
3. ボタン単位のPR表記を外し、ページ上部の常時表示にしたことは、ステマ規制の観点で十分か。
4. 数値検証で見るべきKPIと、判断の目安（例：詳細表示率、サンプル再生率、送客率、単品と月額の比率）。
5. アダルトアフィリエイトで現実的な集客チャネルと、最初に試す順番。
6. 本番化の前に必ずやるべきこと（年齢確認、規約確認、公開先、計測）の優先順位。
7. 見落としている大きなリスクや、もっと効く改善案。
